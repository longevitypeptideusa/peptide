# Longevity Labs USA static catalog

Static, GitHub Pages compatible Turkish product catalog. No build step is required.

## WhatsApp contact

Before publishing, edit config.js and set WHATSAPP_NUMBER to the business number in international format, digits only. Example: 905XXXXXXXXX.

## GitHub Pages

1. Push the site files to the repository's main branch.
2. In the repository, open Settings → Pages and select GitHub Actions as the build and deployment source.
3. The workflow in .github/workflows/pages.yml publishes the site after each push to main.

The original price and guide images and the supplied CoA PDFs are kept at the repository root. Shopier store links are included in the footer.
